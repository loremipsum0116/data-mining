# OECD PIAAC 데이터

`piaac_employed_24.csv`는 OECD 성인역량조사(PIAAC) 2주기 통계표에서 정리한 24개국의 국가별 집계값이다. 조사 시기는 2022~2023년이며 소득 단위의 기준연도는 2022년이다.

| 열 | 의미 |
| --- | --- |
| `Country` | 국가명 |
| `Numeracy_Score` | 취업자의 평균 수리력 점수 |
| `Wage_Metric` | 취업자 및 자영업자의 시간당 세전 소득 중앙값, 보너스 포함 |
| `Wage_Unit` | 구매력평가(PPP) 보정 2022년 USD/시간 |
| `Survey_Year` | 조사 시기 및 주기 |
| `Source_Numeracy` | 수리력 원본 URL, 시트, 셀 |
| `Source_Wage` | 소득 원본 URL, 시트, 셀 |

## 원본과 추출 위치

- [OECD 원본 Excel](https://stat.link/files/b263dc5d-en/smlvj6.xlsx)
- `A.4.1 (N)`의 B열: 취업자 전체 평균 수리력. 정규교육 중이 아닌 25~65세 성인 대상.
- `A.4.7 (N)`의 AB열: 전체 수리력 수준을 합한 시간당 소득의 50백분위수.
- 국가별 원본 셀 주소는 CSV의 두 `Source_` 열에 기록되어 있다.

24개국, 두 지표 48개 값은 지정된 원본 셀과 대조했다. 실습에서는 반올림하지 않은 CSV 값으로 계산한다. 데이터의 권리와 이용 조건은 원 제공자인 OECD에 따른다.

## 해석 범위

점 하나는 개인이 아닌 국가를 나타낸다. 상관계수는 선택한 24개국을 동일한 가중치로 비교한 결과이며, 개인 수준의 관계나 인과관계를 나타내지 않는다. 개인 응답자 수와 국가 수를 혼동하지 않는다.
